# Raiku Live Transcript

Raiku Live Transcript is a modern web-based interface designed to display realtime voice discussion transcripts from the Raiku Discord community using the liveness.cc transcription endpoint.

The project was built to make community conversations easier to read, search, and explore without needing to listen to full voice recordings or manually browse Discord chats.

## Features

* Realtime transcript fetching
* Live session viewer
* Instant transcript search
* Clean modern dark UI
* Responsive layout
* Automatic transcript refresh
* Organized speaker messages
* Lightweight frontend architecture
* Smooth reading experience
* Searchable conversation history

## How It Works

The application fetches live transcript data directly from the liveness.cc transcription endpoint and automatically renders conversations based on:

* speaker names
* timestamps
* message content
* active sessions

The interface updates dynamically to provide a near realtime transcript viewing experience.

## Tech Stack

* HTML
* CSS
* Vanilla JavaScript
* Fetch API
* Realtime transcription integration

## Use Cases

* Community town hall archives
* Discord voice transcript viewer
* Crypto community discussions
* AI community spaces
* Internal meeting transcripts
* Realtime discussion monitoring

## Design Approach

The UI focuses on:

* readability
* clean spacing
* modern dark aesthetics
* responsive usability
* lightweight performance

The interface uses a modern dashboard-inspired design with:

* Inter typography
* soft neon accent colors
* glassmorphism elements
* smooth layout structure
* optimized transcript readability

This project aims to provide a simple, fast, and visually polished way to consume long-form realtime voice discussions directly from the browser.
